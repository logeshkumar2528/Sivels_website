# Sivels Finance static website

Responsive static website template for Sivels Finance.

## Pages

- `index.html` — home page
- `about.html` — company, promoter, legacy and values
- `home-loans.html` — home loan overview
- `home-purchase-loan.html`, `home-construction-loan.html`, `plot-purchase-loan.html`, `home-extension-loan.html`, `home-improvement-loan.html`, `home-loan-balance-transfer.html`, `home-loan-top-up.html` — individual home loan options
- `loan-against-property.html`
- `business-loans.html`
- `micro-loans.html`
- `privacy.html` and `terms.html`

## Preview locally

Open `index.html` in a browser. The site uses relative links and does not require a build step.

## Publish with GitHub Pages

This repository includes a GitHub Actions workflow that publishes the static files to GitHub Pages whenever changes are pushed to the `main` branch. In the repository settings, enable Pages and select **GitHub Actions** as the build and deployment source if it is not enabled automatically.

Before publishing, replace all bracketed company placeholders, confirm the legal and regulatory content with Sivels Finance, add an approved enquiry form endpoint, and update the privacy disclosures to match actual data practices.
